# Expo Design System Skill

Use this skill when designing or implementing web pages, CLI showcases, documentation portals, or developer tools for Expo.

## Design Tokens

- **Background:** `#000000` (deep pitch canvas)
- **Surface:** `#0a0a0a` (raised cards, panels, dialogs)
- **Foreground:** `#ffffff` (primary headings, body text)
- **Muted:** `#737373` (secondary text, metadata, subtle icons)
- **Border:** `#242424` (1px container borders and dividers)
- **Accent:** `#000000` (primary baseline)
- **Accent Secondary:** `#0026a3` (interactive links, focus rings, high-signal badges)

## Typography

- **Headings & Body:** `JetBrains Mono, system-ui, -apple-system, Segoe UI, Helvetica Neue, Arial, sans-serif`
- **Weights:** `400` (Regular), `700` (Bold)
- **Google Fonts:** `https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;700&display=swap`

## Layout Posture

- **Radius:** Strict `8px` on buttons, inputs, and cards.
- **Borders:** `1px solid #242424`.
- **Grid:** 8px baseline spatial rhythm (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`).
- **Hero & Imagery:** Prefer dark-mode isometric device simulators, terminal code blocks, and subtle top ambient flares.

## Assets

- Primary wordmark: `logos/header.svg`
- Exponential icon: `logos/expo-icon.svg`
- Product and hero imagery: `imagery/box-1-dark.webp` through `box-6-mobile-dark.webp`, `imagery/og-image.png`
